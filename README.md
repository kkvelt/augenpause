### Installation:

1. Download `Augenpause.exe` from [Releases](https://github.com/kkvelt/augenpause/releases).
2. Press `Win + R`, enter `%LOCALAPPDATA%`, and create a folder named `Augenpause`.
3. Move `Augenpause.exe` into `%LOCALAPPDATA%\Augenpause\`.
4. Press `Win + R`, enter `shell:startup`, and create a shortcut to `%LOCALAPPDATA%\Augenpause\Augenpause.exe` in that folder.
5. It will launch automatically and will be shown in the system tray when you sign in to Windows.

### How to Uninstall
To uninstall, simply delete `%LOCALAPPDATA%\Augenpause\Augenpause.exe` and remove the startup shortcut.
